✅ Étapes de l’Analyse Exploratoire (EDA)
1. Chargement des données et inspection initiale

Charger le dataset (pd.read_csv).

Afficher :

df.head()

df.info()

df.shape

df.describe()

Vérifier le type des variables (numérique, catégorielle).

2. Vérification des valeurs manquantes

df.isnull().sum()

Pourcentage de valeurs manquantes.

Décider :

suppression,

imputation (mean, mode),

ou laisser en l'état.

3. Analyse univariée

Analyser une variable à la fois :

🔹 Variables numériques :

→ price, duration, days_left

Histogrammes

Boxplots

Statistiques :

moyenne, médiane, min, max

skewness (asymétrie)

🔹 Variables catégorielles :

→ airline, source_city, class, etc.

Comptage des catégories : df[col].value_counts()

Barplots

Vérifier imbalance des classes

4. Analyse bivariée

Analyser les relations entre variable cible (price) et chaque feature.

🔹 Price vs catégorielles

Airline vs Price → boxplots

Source City vs Price → boxplots

Class vs Price → bar charts

Stops vs Price → boxplots

🔹 Price vs numériques

Duration vs Price → scatter plot

Days Left vs Price → scatter plot + trend

5. Analyse multivariée

Matrice de corrélation (seulement variables numériques)

Heatmap

Pairplot si petit dataset (ici trop gros → échantillonner)

6. Détection des outliers

Méthodes :

Boxplots

IQR

Z-score

Décider si on les retire ou pas.

7. Compréhension des distributions

Identifier :

asymétries

skewness importantes
→ peut nécessiter transformation (log, sqrt)

8. Relations importantes à confirmer

Exemples spécifiques à ton projet :

Plus de stops → prix plus bas ?

Business class → prix plus élevé ?

Certaines compagnies → plus chère ?

Moins de jours avant → prix explosent ?

9. Préparation pour le modèle

Après l’EDA :

Encoding (One-Hot ou Ordinal)

Normalisation (selon modèle)

Séparation Train/Test

Feature engineering si nécessaire

🎯 Résumé ultra simple (si tu veux un truc court en 1 minute)

Inspecter les données

Vérifier les valeurs manquantes

Étudier chaque variable

Étudier les relations avec price

Étudier les relations entre variables

Détecter les outliers

Identifier les patterns importants

Préparer les données pour le modèle
